读取 /root/input.xlsx 这个 Excel 工作簿，把每个 sheet 的内容提取出来，按下面格式写到 /root/result.json：

```
{
  "sheets": {
    "<sheet_name>": [["cell", ...], ...],   // 每个 sheet 是行列的二维数组，单元格按字符串保存
    ...
  },
  "sheet_names": ["<sheet_name>", ...]      // 按工作簿中出现的顺序
}
```

要求：
- 每个 sheet 单独成一项，名字与工作簿中一致。
- 单元格的值保留原貌（数字按原值的字符串形式，文本原样保留），空单元格用空字符串 ""。
- 行数和列数与原表一致，不要丢行丢列。
